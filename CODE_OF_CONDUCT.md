# Code of conduct

Compass follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, keep feedback about the work, and don't harass anyone.

It applies in issues, pull requests, discussions and any other project space.

To report a problem, use the repository's private reporting (the **Security** tab, then **Report a vulnerability**) and say it's a conduct report. The maintainer will read it privately and may remove comments, close threads or block accounts that break these rules.
