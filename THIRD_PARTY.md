# Third-party material

Compass has no third-party code dependencies: `Core/Package.swift` declares none, and the app links only Apple frameworks.

It bundles four font families, each under the SIL Open Font License 1.1:

| Font | Licence file |
| --- | --- |
| Geist | [App/Fonts/Geist-OFL.txt](App/Fonts/Geist-OFL.txt) |
| Geist Serif | [App/Fonts/GeistSerif-OFL.txt](App/Fonts/GeistSerif-OFL.txt) |
| Public Sans | [App/Fonts/PublicSans-OFL.txt](App/Fonts/PublicSans-OFL.txt) |
| Spectral | [App/Fonts/Spectral-OFL.txt](App/Fonts/Spectral-OFL.txt) |

The OFL allows the fonts to be bundled with software under any licence, including this repository's MIT licence. The fonts themselves stay under the OFL.
